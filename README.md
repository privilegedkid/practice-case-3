# Практическая работа — Кейс-задача №3

## База данных «Туризм»

В рамках кейс-задачи разработана база данных для туристической системы.

## Структура базы данных

База данных содержит три основные таблицы:

* `tourists` — информация о туристах;
* `tours` — информация о доступных турах;
* `bookings` — информация о бронированиях.

## Связи между таблицами

Таблица `bookings` связывает туристов и туры с помощью внешних ключей:

* `tourist_id` — ссылка на туриста;
* `tour_id` — ссылка на тур.

## Возможности

База данных позволяет:

* хранить информацию о туристах;
* хранить информацию о туристических предложениях;
* регистрировать бронирования;
* определять, какой турист забронировал конкретный тур;
* получать информацию о стоимости, стране и городе выбранного тура.

## Используемые технологии

* SQL
* MySQL

## Файл базы данных

SQL-код создания и заполнения базы данных находится в файле `tourism.sql`.

## Результат

Создана реляционная база данных «Туризм» со связанными таблицами и тестовыми данными.
