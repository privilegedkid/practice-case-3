# Практическая работа — Кейс-задача №3

## База данных «Туризм»

В рамках кейс-задачи разработана реляционная база данных для туристической системы.

## Структура базы данных

База данных состоит из четырех таблиц.

### Справочные таблицы

* `tourists` — содержит информацию о туристах;
* `countries` — содержит список стран;
* `hotels` — содержит информацию об отелях.

### Таблица переменной информации

* `bookings` — содержит сведения о бронированиях туристических поездок.

Таблица `bookings` содержит внешние ключи:

* `tourist_id` — ссылка на таблицу `tourists`;
* `country_id` — ссылка на таблицу `countries`;
* `hotel_id` — ссылка на таблицу `hotels`.

Таким образом, таблица переменной информации связана со справочными таблицами посредством внешних ключей.

## Возможности базы данных

Разработанная база данных позволяет:

* хранить информацию о туристах;
* хранить список туристических стран;
* хранить информацию об отелях;
* регистрировать бронирования;
* хранить даты начала и окончания поездки;
* хранить стоимость поездки;
* определять туриста, страну и отель для каждого бронирования;
* получать объединенную информацию с помощью SQL-запросов.

## Используемые технологии

* MySQL;
* SQL;
* внешние ключи;
* первичные ключи;
* реляционные связи между таблицами.

## Файл базы данных

SQL-скрипт создания структуры базы данных, связей и тестовых данных находится в файле:

`tourism.sql`

## Результат

Создана база данных «Туризм», содержащая три справочные таблицы и одну таблицу переменной информации.

Все таблицы имеют первичные ключи, а таблица `bookings` связана со справочными таблицами с помощью внешних ключей.
